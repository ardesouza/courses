# Projeto AWS — Redução de Custos Operacionais

## Objetivo

Este projeto tem como objetivo propor a implementação de três serviços da Amazon Web Services (AWS) na empresa fictícia Abstergo Industries, visando à redução de custos operacionais e à otimização dos recursos de tecnologia da informação.

A proposta busca demonstrar como a utilização de serviços em nuvem pode contribuir para uma infraestrutura mais eficiente, escalável e economicamente sustentável.

## Serviços AWS propostos

| Serviço | Objetivo |
|---|---|
| AWS Cost Explorer | Monitorar gastos e identificar oportunidades de economia. |
| Amazon EC2 Auto Scaling | Ajustar a capacidade computacional conforme a demanda. |
| Amazon S3 | Otimizar os custos de armazenamento por meio de regras de ciclo de vida. |

## Benefícios esperados

- Redução de despesas com infraestrutura de TI.
- Melhor aproveitamento dos recursos computacionais.
- Maior controle e previsibilidade dos custos.
- Otimização do armazenamento de dados.
- Aumento da eficiência operacional.
